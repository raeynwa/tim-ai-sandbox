# Uji Git Workflow — Tim AI Sandbox

Tim AI Sandbox adalah repositori uji coba untuk memvalidasi alur kerja kolaborasi tim AI sebelum diterapkan pada proyek produktif. Sandbox ini dipakai untuk menguji pembuatan branch, penulisan dokumen ke `docs/`, serta pembukaan Pull Request sesuai skill `git-workflow` tanpa mengganggu repositori utama. Melalui uji ini, setiap peran — termasuk Analyst — dapat memastikan kepatuhan terhadap konvensi penamaan branch, format commit, dan templat deskripsi PR. Hasil uji menjadi rujukan untuk perbaikan proses dan dokumentasi alur kerja tim AI ke depan.
